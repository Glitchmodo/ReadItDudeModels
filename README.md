# Read It, Dude voice models

Versioned, full-precision Supertonic 2 model downloads for Read It, Dude by Glitchmodo.

Download the four pinned model assets from the [supertonic-2-v1 release](https://github.com/Glitchmodo/ReadItDudeModels/releases/tag/supertonic-2-v1). The browser extension handles downloading, SHA-256 verification and offline caching. This repository contains model data and licensing notices; the browser extension runtime and voice presets ship with the extension.

The gzip files expand to the original full-precision model bytes, without quantization. The vector estimator exposes existing attention outputs for word highlighting without changing learned weights or neural operations.

Models use the BigScience Open RAIL-M license. See LICENSE.txt, THIRD-PARTY-NOTICES.txt and checksums.json in the release for conditions, provenance and integrity information.
